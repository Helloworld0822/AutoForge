# 견적 및 코딩 스킬 검증

2026-10-30, 로컬 코드 및 production frontend build 기준.

## 확인 결과

- `cargo test --lib`: 55개 통과. 금액·부가세, 잘못된 날짜·금액,
  AI 응답 변환, 파일 저장·수정, API 인증, 실행 중 스킬 저장을 포함한다.
- `cargo fmt --all -- --check`, `cargo clippy --all-targets -- -D warnings`: 통과.
- `npm run build`: 통과. `npm run lint`: 기존 Fast Refresh 경고 2개
  (`ModelConfigPanel`, `AuthContext`)가 남아 있다. 새 경고는 없다.
- 실제 브라우저에서 견적 저장·재열기, 요구사항·단가 보존, 부가세 계산,
  스킬 입력과 프로젝트 상세의 설정 저장을 실제 API로 확인했다.
- AI 응답을 네트워크에서 모의하여 대기 → 완료 → 항목 반영 → 실제 저장을 확인했다.
  서버의 AI JSON 변환은 별도 Rust 테스트로 검증했다.
- 가견적서·견적서 A4 출력, 한글, 합계, 32개 작업의 2페이지 출력,
  반복 표 머리글, 마지막 항목·합계·비고를 모든 페이지 이미지로 확인했다.
- 1440px, 390px 화면을 확인했다. 320px에서 줄 높이 1.5, 글자 간격 0.12em,
  단어 간격 0.16em, 문단 간격 2em을 적용한 견적·새 프로젝트·상세 화면에서
  가로 넘침이 없었다. 발견된 스킬 필드와 모델 설정 버튼 넘침을 수정했다.

## 제한 및 증거

실제 Cursor 호출은 API 키가 없어 실행하지 않았다. 토큰 절감량도 측정하지 않았다.
스킬은 선택한 Markdown 지침을 전달하며 연결된 스크립트·외부 스킬을 설치하지 않는다.
PDF는 브라우저 인쇄 창의 'PDF로 저장'을 사용한다.

세션 증거: `/tmp/autoforge-estimate-evidence/`의 `results.json`,
`accessibility.json`, 화면 PNG, `preliminary.pdf`, `quotation.pdf`,
`quotation-multipage.pdf` 및 페이지 PNG. 임시 디렉터리이므로 장기 보관 대상은 아니다.
검증 과정의 잘못된 선택자·키 입력 자동화는 수정 후 다시 실행했다.
사용자의 기존 `docs/reviews/` 작업은 수정하지 않았다.
